Lumen Sync 2.4 release notes

Lumen Sync keeps folders in step between a phone and a desktop. Version 2.4 is a maintenance release.

Changes

  • Conflict copies now keep the original file's modification time.
  • The Android client resumes uploads after a network switch instead of starting over.
  • Initial scans of large folders are about 30% faster.
  • The minimum supported Android version is now 10.

Known issues

Symbolic links outside the synced folder are skipped. Workaround: sync the link target instead.
